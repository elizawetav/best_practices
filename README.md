# Анализ эффективности рекламных офферов в Яндекс.Директ для жилого комплекса бизнес-класса

#### Цель и задачи проекта
Провести анализ рекламных кампаний за 3 месяца на основе данных Roistat для определения наиболее эффективных рекламных заголовков и их офферов в Яндекс.Директ.

Основные задачи проекта:
- Проанализировать эффективность отдельных рекламных заголовков по ключевым метрикам: расходы, клики, лиды и целевые лиды
- Рассчитать продуктовые и маркетинговые метрики эффективности: CTR, CPL, CR в лиды, CPQ и CR в целевые лиды
- Выявить наиболее и наименее эффективные рекламные объявления по стоимости и качеству лидов
- Сегментировать офферы по смысловым группам: тип недвижимости + тип оффера
- Определить наиболее эффективные связки «тип квартиры + оффер» для масштабирования рекламных кампаний
- Сформировать рекомендации по отключению неэффективных объявлений и гипотезы для дальнейшего тестирования

#### Методология и инструменты
- Python (pandas, numpy, re)
- Визуализация данных (seaborn)
- Агрегация и группировка рекламных данных
- Сегментация текстов рекламных объявлений с помощью регулярных выражений
- Смысловая кластеризация офферов 
- Анализ эффективности маркетинговых гипотез

#### Источники данных
Внутренняя база данных компании из Roistat
